# 📊 Project 3: Auditing and Mitigating Algorithmic Bias in HR Screening Systems

## 🎯 Overview
This Data Science research project audits algorithmic bias in automated resume screening systems and applies pre-processing debiasing (data re-weighing) to improve fairness metrics while maintaining high predictive accuracy (96%+).

## 🛠️ Key Features & Metrics
- **Baseline Model:** Evaluates Disparate Impact Ratio and selection rate disparity across protected groups (Gender).
- **Debiasing Method:** Applies sample re-weighing to meet the 80% Fairness Rule Target.
- **Interactive Dashboard:** Built using Streamlit and Seaborn for real-time fairness vs. accuracy trade-off visualization.
