# 📊 Project 3: Auditing and Mitigating Algorithmic Bias in HR Screening Systems

## 🎯 Overview
This Data Science research project audits algorithmic bias in automated resume screening systems and applies pre-processing debiasing (data re-weighing) to improve fairness metrics while maintaining high predictive accuracy (96%+).

## 🛠️ Key Features & Metrics
- **Baseline Model:** Evaluates Disparate Impact Ratio and selection rate disparity across protected groups (Gender).
- **Debiasing Method:** Applies sample re-weighing to meet the 80% Fairness Rule Target.
- **Interactive Dashboard:** Built using Streamlit and Seaborn for real-time fairness vs. accuracy trade-off visualization.

## 🚀 Enterprise Customer Churn & Revenue-at-Risk Engine

An executive-grade predictive analytics platform engineered to model enterprise customer churn probabilities, quantify projected annual revenue loss ($MRR \times P(Churn)$), and provide interactive retention strategy simulation.

### 🌟 Technical Highlights
* **Predictive Analytics:** XGBoost Gradient Boosting Classifier fine-tuned on customer behavioral metrics.

* **Financial Risk Quantification:** Revenue-at-risk scoring engine converting probability predictions into financial metrics ($).
* **Executive What-If Simulator:** Interactive Streamlit framework enabling real-time testing of customer retention interventions.
